# Resonance

**A modern, Rust-based API testing tool built with a Linux-first mindset.**

Resonance is a personal project born out of my interest in building a fast, lightweight, offline-friendly API testing tool for Linux.

As a backend developer working primarily with Go and Python, I spend time building APIs and working with HTTP. I wanted a desktop tool that feels modern, stays responsive, avoids unnecessary overhead, and works well in a Linux environment.

That's why I'm exploring Rust and Slint to build Resonance: a native desktop application with a clean interface, asynchronous HTTP networking, and a focus on performance and usability.

### Why I'm building this

- **Linux first:** Designed with Linux desktops and a GNOME-inspired interface in mind.
- **Offline-friendly:** Keep requests, collections, environments, and history available locally without requiring a cloud account. Sending requests to remote APIs still requires network access when those endpoints aren't local.
- **Lightweight:** Avoid unnecessary runtime and resource overhead while keeping the application responsive.
- **Modern UI:** A clean three-pane workspace with dark, light, and system themes.
- **Rust-powered:** Explore Rust's performance, safety, and concurrency model in a real desktop application.
- **Cross-platform ambitions:** Start with Linux, with Windows and macOS as future targets.

### Development approach

This is a **vibe-coded, AI-assisted project**. I'm using AI to help explore implementation choices, generate and refine code, and troubleshoot problems. My goal is to review the generated code, understand the architecture, test features, and document decisions rather than blindly accept code that happens to compile.

Resonance is also a way for me to learn Rust through practical software engineering.

**Status:** Early development. Features, performance, and platform support will be validated as the project evolves.
